# Mathematical Formulation

For adjacency matrix `A` and degree matrix `D`, the normalized graph Laplacian is `L = I − D⁻¹ᐟ²AD⁻¹ᐟ²`. Eigenvectors expose structural communities and low-frequency graph behavior.

A personalized random walk uses `x_{t+1} = αx_tP + (1−α)s`, where `s` is a restart vector. These signals can be combined by an agentic validator to rank suspicious graph nodes.
